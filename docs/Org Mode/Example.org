#+TITLE: Org Mode example
#+AUTHOR: SilverBullet

This is a real =.org= page in the SilverBullet docs space. Open it to see the
Org parser driving live preview, and edit it to see indexing update.

* Structure
Org headlines nest with stars, and SilverBullet indexes each one as a header —
so it shows up in the outline and in header queries, exactly like a Markdown
=#= heading.

** Emphasis
Text can be *bold*, /italic/, _underlined_, +struck through+, =verbatim= or
~code~. Markers only bind at word boundaries, so snake_case_names and 2 * 3 * 4
stay plain.

** Lists and tasks
- a plain item
  - nested by indentation
    - and deeper still
- [ ] an open task
- [X] a finished task
1. first
2. second

* Blocks
#+BEGIN_SRC lua
local total = 0
for i = 1, 10 do
  total = total + i
end
print(total)
#+END_SRC

#+BEGIN_QUOTE
Everything in a quote block is styled as a quotation.
#+END_QUOTE

* Tables
| part   | cost | in stock |
|--------+------+----------|
| bolt   |   10 | yes      |
| washer |    2 | yes      |
| flange |  250 | no       |

* Drawers
Property drawers are parsed as structured nodes rather than prose, so they stay
out of the indexed text of the page.

:PROPERTIES:
:COST: 250
:OWNER: warehouse
:END:

# A comment line is styled as a comment and never indexed.
